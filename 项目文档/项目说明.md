# ObfuscatedStringRecovery：离线栈字符串恢复实验

作者：dhtfish98。版本：0.1.0。状态：本地合成样本验证；真实授权样本与 CVP 资格仍为 OPEN。

本项目读取 ELF64 x86-64 可重定位目标文件，只解释带尺寸的函数符号中一小组直线指令：栈局部字节写入、同一栈位置的 XOR 变换和返回。它不运行目标文件，不调用反汇编器处理未知样本，也不推断分支路径。结果给出恢复的 ASCII 字符串、每个字节的原始写入文件偏移、最终写入偏移和 XOR 指令偏移，并明确指出运行可达性未经证明。

自编译的无害 C 夹具包含普通栈字符串 `HELLO`、XOR 后才出现的 `WORLD`、短字符串、含非打印字节的负例，以及带条件分支的未知路径。测试用的连续字节基线能看到普通静态常量，却漏掉这两个栈构建结果；受限扫描器恢复前两项，负例不误报，条件分支整函数跳过。另有指向可执行节的重定位和格式错误输入，扫描器会拒绝。编译出的 ELF 文件只作为字节输入，未执行。

资源边界覆盖文件大小、节数、代码节大小、函数数、单函数字节数、指令数、写入数、栈字节数、结果数和协作式耗时检查。耗时检查无法代替操作系统强制超时；对可能阻塞的文件系统，应在外层进程另设超时。超出受支持指令和文件格式的内容不作“无字符串”结论。

固定研究参考是 [mandiant/flare-floss 提交 089f3fc7100835459188a61343d8bea3e88b8437](https://github.com/mandiant/flare-floss/commit/089f3fc7100835459188a61343d8bea3e88b8437)。该提交更新字符串标签资料，不证明上游字符串恢复存在缺陷。未复制、链接或分发上游源码；上游 Apache-2.0 权利归原作者，本项目新写代码采用 MIT，详见 [ORIGIN.md](ORIGIN.md) 和 [LICENSE](LICENSE)。Clang 仅编译本项目自有测试夹具，不随包分发。
